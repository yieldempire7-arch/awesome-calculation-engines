## ⚡ Architectural Philosophy

1. **Zero Framework Overhead**: Built with pure, idiomatic Vanilla JavaScript (ES6+), standard semantic HTML5, and modern CSS variables. Loads in under **100 milliseconds** globally on Cloudflare edge.
2. **100% Client-Side Computation**: All mathematical formulas, amortization schedules, and sensitivity tables execute locally in your browser. Zero server roundtrips, zero telemetry tracking, and complete financial privacy.
3. **Reactive Visualizations**: Inline SVG chart generators rendering dynamic 5-year cash-flow curves and payback horizons.
4. **1-Click Executive Deal Memo Export**: Built-in print engine formatting underwriting outputs into institutional PDF investment memos with signature authorization blocks.
5. **Universal Widget Embedding**: Clean, responsive iframe widget snippets ready to drop into WordPress, Webflow, Ghost, or React apps.
