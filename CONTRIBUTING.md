# Contributing to Awesome Calculation Engines (ToolsVault)

We love contributions! Whether you're adding a new engineering model, optimizing financial math formulas, or fixing typos, here's how to get involved.

## Submission Guidelines

1. **Zero External Dependencies**: Calculators must use pure Vanilla JavaScript without external frameworks (no React, Vue, Angular, or jQuery runtime required).
2. **Client-Side Reactive Math**: Calculations must update instantly on user input using `oninput` event listeners.
3. **Responsive Mobile-First UI**: Use CSS Flexbox/Grid and CSS variables for automatic Light/Dark mode support.
4. **Structured Metadata**: Include Schema.org microdata and standard meta tags.

## Step-by-Step Pull Request Process

1. Fork the repo.
2. Create your branch (`git checkout -b feature/amazing-solver`).
3. Add your tool HTML file into the appropriate directory.
4. Test locally in your browser.
5. Commit your changes (`git commit -m 'feat: Add Solar Canopy Bifacial Model'`).
6. Push to your branch (`git push origin feature/amazing-solver`).
7. Open a Pull Request.

Thank you for helping build the most comprehensive open collection of calculation tools on the web!
